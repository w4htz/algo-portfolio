# Домашнее задание № 2 · сложность и O-нотация

Срок — до начала занятия 4. Три задания, у каждого свой файл в этой папке.

## Задание 1. Оценить двенадцать функций

В `fragments.py` двенадцать функций. Для каждой впишите в `answers.py`
оценку времени (`TIME`) и памяти (`SPACE`), а для двух функций ещё и худший
случай (`WORST_CASE`). ИИ не использовать.

Проверка:

```
pytest lesson_02/test_lesson_03.py -q
```

Сейчас тест показывает `26 failed`, нужно довести до `26 passed`.
Оценки пишутся без констант: `O(n)`, а не `O(2n)`; если входов два —
`O(n + m)`.

## Задание 2. Выбрать решение под ограничение

В `limits.md` шесть задач с ограничениями на размер входа. По каждой: какое
решение уложится во время и почему — с расчётом числа операций.
Ориентир: около 10⁷ простых операций в секунду.

Здесь ИИ можно: дайте модели условие, пересчитайте её ответ сами и в пункте 7
запишите, где она ошиблась.

## Задание 3. Оценить чужой код

В `acceptance_vetclinic.py` рабочая функция. Менять её не нужно. Ответьте
в `acceptance.md`: сколько она работает, сколько занимает памяти, при каком
входе работы больше всего и какая строка стоит дороже, чем кажется.
ИИ не использовать.
